# Cobblestone S17

## MODの概要
Minecraft Java版の play.cobblestone.gg 向けに、Cobblestone HelperをS17用へ改変したクライアントMODです。Minecraft 1.21.11／Fabricに対応しています。

## 農場ワープ
R キー、または /wf で農場選択画面を開きます。作物一覧をS17用に更新し、選んだ農場へ移動できます。

## ギルドクエストHUD
討伐・収穫の対象や達成状況を画面に表示します。Cobblestoneのスコアボードに合わせた配色を採用しています。クエスト情報は /guild からクエスト画面を開いて同期します。

## HUDの位置・サイズ変更
ギルドクエストHUD、右側のスコアボード、上部のボスバーを自由に配置できます。右Shift、または /s17hud で編集画面を開き、ドラッグで移動、ホイールや ＋／− でサイズを変更できます。

## ボスバーの全件表示
画面上部のボスバーが途中で表示されなくなる制限を解除します。サーバーから受信した全件を、自動縮小や複数列への配置で表示します。

## 会話とサーバー通知の分離
同梱のChat Utilitiesと専用設定で、プレイヤーの会話とサーバー通知を別のチャット欄に表示します。メッセージの書式で分類するため、未対応の会話は通知側に表示される場合があります。

## プレイヤー非表示
H キーで、ほかのプレイヤーの表示・非表示を切り替えられます。

## 自動リスポーン
死亡後、設定した待ち時間で自動的にリスポーンします。初期設定では無効です。

## ドロップアイテムの発光
落ちているアイテムに発光表示を付け、見つけやすくします。設定画面で有効・無効や色を変更できます。
